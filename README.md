# 🎓 Scholarship Tracker

A web application designed to help students organize and manage their university scholarship applications.

## 🌟 Features

- Add new university applications.
- Edit and delete applications.
- Track application statuses.
- Manage application deadlines.
- Search for universities and countries.
- Filter applications by status.
- Sort applications by deadline, university, or country.
- Save data using browser Local Storage.
- Export application data.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- GitHub Pages

## 🎯 Project Purpose

The purpose of this project is to help students organize their scholarship applications, monitor deadlines, and manage their application progress in one place.
